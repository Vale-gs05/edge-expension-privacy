# 发布隐私政策页面

此目录可直接作为 GitHub Pages 网站内容。页面公开后，将浏览器地址栏中的完整 HTTPS 地址填写到 Edge Partner Center 的 Privacy policy URL。

1. 登录 GitHub，创建一个新的 **Public** 仓库，例如 `baidu-clean-sync-privacy`。
2. 将本目录的 `index.html` 上传到仓库根目录并提交。
3. 打开仓库 **Settings → Pages**。
4. 在 **Build and deployment** 选择 **Deploy from a branch**，分支选 `main`，目录选 `/(root)`，点击 **Save**。
5. 等待 GitHub Pages 部署完成，打开显示的 `https://<GitHub用户名>.github.io/baidu-clean-sync-privacy/` 地址确认页面可访问。
6. 把该 HTTPS 地址填入 Partner Center 的 **Privacy policy URL**。

Edge 商店页面上的支持邮箱应真实可联系，并与页面中“商店页面列出的支持联系方式”的说明一致。
